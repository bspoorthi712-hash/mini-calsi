# Mini Calculator

A simple calculator project made with HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Percentage and decimal input
- Clear and backspace buttons
- Keyboard support
- Responsive layout
- Works offline with no dependencies

## Run
Extract the ZIP and open `index.html` in a modern browser.

## Upload to GitHub
Create a repository on GitHub, upload `index.html` and `README.md`, then optionally enable GitHub Pages from **Settings → Pages** using the `main` branch and `/(root)`.
